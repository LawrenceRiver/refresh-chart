# SVG 数据重绘与核验

用于从已选设计落地准确矢量图，不规定所有图表都用同一布局或配色。

## 数据来源与冲突

- C 是数值依据，B 是内容与约束语境，A 是视觉参考，AI 预览是布局草案。
- 明确 CSV 字段与系列映射；检查 BOM、时间格式、排序、重复键、单位和多文件连接键。
- C 与 B 不一致时列出差异，不静默混用。仅视觉生成偏差按真实数据修复；若冲突改变变量定义或结论，先澄清。
- 不凭文件名判断意义。例如“库存边界.csv”可能保存区间边界时点的库存轨迹，而不是上下限参数表。约束上下限需要 B 标注或数据说明支持，不能只用观测极值当约束。

## 几何编码

- 连续状态在真实采样点间连接；分时决策、价格等按区间保持时使用阶梯，不加平滑。N 个区间可能对应 N+1 个边界时点，先确认定义，不硬编码到所有图。
- 保留零、负值及对数轴适用范围。改变轴类型、归一化、聚合或计算密度是语义变换，须在方案中说明，不能换样式时暗中加入。
- 堆积面积表示可相加分量；两条曲线间填充表示差值；基线到曲线的面积不是任意替代项。例如购电与净负荷间的充放电差值应填在两曲线之间，不能统一从零填充。
- 显式坐标映射：线性轴 `x = left + (t - t_min)/(t_max - t_min) * width`，`y = top + height - (v - v_min)/(v_max - v_min) * height`。保留必要数据点，不用 AI 生成峰高或位置。
- 阶梯路径每个区间起点和终点使用同一数值；不要错用最后采样时刻代替最后区间终点。

## 可编辑性与字体

- 根 SVG 写明 width、height、viewBox；系列与组件使用稳定且语义化的 id。数据曲线与装饰填色分开，文本独立，可附数据键辅助核验。
- 使用 path、rect、line、circle、text 等；不要求每条曲线拆成大量独立节点，不强制重建无关参考轮廓。
- 中文 `font-family="PingFang SC"`；公式 `font-family="STIX Two Math"`。变量可用字体支持的 Unicode 数学斜体字符或经渲染验证的斜体 span；数字、括号、等号和单位正常字形。不要将整个公式设为斜体。
- 上下标用可编辑 tspan；根号横线覆盖整个被开方项。字体本机存在不代表其他电脑已安装，可简短说明字体需求，不自动转曲。

## 可复现核验

保存字段映射和构建脚本，可在交付目录复制输入数据增强可移植性。不要把本次用户的私有路径或固定数值写进技能本身。

1. 输入：样本数、时间/分类顺序、缺失值、单位，多表同一时点或类别的一致性。
2. 关系：只按给定定义检查。例如功率平衡、差值填色、初末状态、明确上下限；不要猜测效率或符号约定。
3. 输出：解析最终 SVG，对数据路径/柱形坐标逆映射；检查时间位置、数值、区间终点、系列完整性。容差按小数序列化、图尺寸和量纲制定，报告实际最大误差。
4. 视觉：按正确宽高完整渲染，确认文字无裁切、图例对应、公式正常、边界清晰。浏览器截图是预览，不改变 SVG 本体。
5. 报告：区分原始表一致性误差、模型关系残差、SVG 坐标舍入误差。无 CSV 时写“已与原 SVG 核对”，不能写“原始数据核验通过”。

按实际数据编码选择核验方法，不要仅断言元素数量就声称数据准确。
